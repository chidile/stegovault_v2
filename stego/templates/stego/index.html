Features

LSB Encoding

Each bit of your message replaces the least significant bit of a pixel's colour channel — a shift invisible to the human eye.

AES-256-GCM Lock

Add a password to encrypt the payload before embedding. Uses PBKDF2-SHA256 key derivation and AES-256-GCM authenticated encryption.

Password Pop-up

When decoding, if the image is locked, a secure password dialog automatically appears — no guessing required.

Export TXT & PDF

After decoding, save the message as a plain text file or a styled PDF report with one click.

⚠

Important: Always use PNG or BMP as the carrier image. JPEG compression destroys LSB data and will corrupt hidden messages. Encoded images are always saved as PNG.
